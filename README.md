# Behind The Creator

The personal site of Jasleen, founder of amaris ct.

It opens as a sealed letter: break the wax seal, pull the letter out, and it unfolds into a collage of old-master paintings (Botticelli, Vermeer, Michelangelo, Raphael, Cole, Constable and more, all public domain via Wikimedia Commons), ending with the close of the letter.

Everything lives in one `index.html`; the paintings load from Wikimedia Commons.

Live (once GitHub Pages is on): https://amarisct.github.io/Behind-The-Creator/

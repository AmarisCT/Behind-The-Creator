# Behind The Creator

The personal site of Jasleen, founder of amaris ct.

It opens as a sealed letter: break the wax seal, pull the letter out, and it unfolds into a Renaissance-garden site that ends with the close of the letter.

Everything (art included) is in one self-contained `index.html`. The paintings are drawn in SVG, so there are no image files to manage.

Live (once GitHub Pages is on): https://amarisct.github.io/Behind-The-Creator/

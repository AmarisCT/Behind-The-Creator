# Behind The Creator

The personal site of Jasleen, founder of amaris ct.

It opens as a sealed letter: break the wax seal, pull the letter out, and it unfolds into a Renaissance garden painted in SVG, with lace, filigree, a works catalogue, a sea of roses and a Venus shell. A square envelope opens into a notecard for contact, and a ribbon at the very end folds the site back into the letter and re-seals it.

Everything (all the art included) lives in one self-contained `index.html`.

Live (once GitHub Pages is on): https://amarisct.github.io/Behind-The-Creator/
